# 🚴 Boucles Vélo : version iPhone

La version web de [Boucles Vélo](https://github.com/narnia1633/boucles-route), qui crée des boucles à vélo
(route, gravel, VTT) autour de toi. Elle marche dans Safari et s'installe sur l'écran d'accueil comme une appli.

**👉 [narnia1633.github.io/boucles-route-web](https://narnia1633.github.io/boucles-route-web/)**

## Installer sur l'iPhone

1. Ouvre l'adresse ci-dessus dans **Safari**.
2. Touche le bouton **Partager**, puis **Sur l'écran d'accueil**.
3. Lance **Boucles Vélo** et autorise la localisation.

## Ce qu'elle fait

- 3 propositions de boucles ou d'allers-retours pour la route, le gravel ou le VTT.
- Direction au choix, dont **vent de face à l'aller**, et préférence de relief.
- Distance, dénivelé, temps estimé, pente maximale et part de chemins pour chaque parcours.
- Profil d'altitude coloré selon la pente.
- Export et partage en GPX, favoris, import de fichiers GPX.
- Mode sortie : vitesse, distance, moyenne, kilomètres restants et alerte hors parcours.

Toutes les fonctions sont décrites dans le [dépôt de la version Android](https://github.com/narnia1633/boucles-route).

## Bon à savoir

- Pendant une sortie, garde l'écran allumé : iOS met le suivi GPS en pause quand l'écran se verrouille.
- Les favoris sont gardés dans Safari, sur ce téléphone.
